# ATEMPORAL · Casa

Página interactiva de la etapa **Casa**.

## Cómo trabajar (GitHub Desktop)

1. **Clonar** (una sola vez): en GitHub Desktop, *File → Clone repository* → pestaña *URL* → pegar `https://github.com/juanmovio/atemporal-casa` → elegir carpeta.
2. **Antes de empezar a trabajar**: *Fetch origin* → *Pull origin*, para tener lo último de todos.
3. **Después de cambiar algo**: escribir un resumen abajo a la izquierda → *Commit to main* → *Push origin*.
4. Avisen en el grupo qué archivo están tocando, para no pisarse.
